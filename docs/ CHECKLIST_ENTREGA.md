# Entrega — Rota Inteligente

## Arquivos
- `README.md`: documentação do projeto.
- `src/main.py`: implementação do A*, agrupamento K-Means e otimização da ordem das entregas.
- `data/entregas.csv`: dados simulados.
- `docs/grafo.png`: resultado visual.
- `docs/ROTEIRO_VIDEO.md`: roteiro do pitch.
- `requirements.txt`: dependências.

## Demonstração
Execute:

```bash
pip install -r requirements.txt
python src/main.py
```

O terminal mostrará os grupos, a rota de referência, a ordem otimizada, a rota calculada pelo A* e a redução estimada da distância.

## Observação acadêmica
Os dados e o mapa são simulados. O objetivo é demonstrar os conceitos exigidos na disciplina. Uma versão de produção poderia integrar mapas, trânsito e restrições operacionais reais.
